# docs-export — הפקת דוח מדווח ל-DOCX

אפליקציית **board view** של monday.com (צד-לקוח, CDN) שמפיקה דוח יומי או שבועי
לקובץ `.docx` — עם הכותרת העליונה והתחתונה מתוך תבנית שהמנהל העלה, בלוקי טקסט
קבועים מראש, ובאמצע טבלה בת ארבע עמודות עם תאי מיזוג.

**המסמך הוא דוח של המדווח, לא של הוועדה.** כל משתמש רואה רק אייטמים שהוא מופיע בהם,
והדוח שהוא מפיק הוא שלו — גם כשהוא בוחר כמה ועדות אזוריות. לכן שם הוועדה הוא עמודה
בטבלה, ולא משהו שמפצל את המסמך.

## התפעול

1. המשתמש נכנס ל-board view.
2. בוחר **יומי** או **שבועי** — תמיד נוכחי (יומי = היום; שבועי = השבוע הנוכחי, ראשון–שבת).
3. בוחר **ועדה אזורית אחת או יותר**, מתוך הוועדות שיש לו אייטמים בהן בטווח.
4. לוחץ **הפק דוח** → הקובץ יורד למחשב.

## ההגדרות (מנהלי לוח בלבד)

| שדה | מה זה |
|---|---|
| מזהה לוח | לוח היעד. לא בהכרח הלוח שה-view יושב עליו. |
| פעולה | עמודה 1 בטבלה (הימנית ביותר). שורות רצופות עם אותו ערך מקבלות תא ממוזג. |
| שם הועדה האזורית | עמודת **מירור**. גם עמודה 2 בטבלה וגם המסנן הרב-בחירתי. |
| דיווח | עמודה 3 בטבלה. |
| תאריך דיווח | עמודה 4 בטבלה **וגם** עמודת סינון הטווח. מיפוי אחד, שני תפקידים. |
| עמודת האחראי | עמודת **people**. לא בטבלה — קובעת אילו אייטמים כל משתמש רואה. |
| כותרות הטבלה | דריסה אופציונלית לכל אחת מארבע הכותרות; ריק = כותרת העמודה מהלוח. |
| תבנית DOCX | קובץ `.docx` שממנו נלקחים הכותרת העליונה והתחתונה (כולל לוגו). |
| בלוקי טקסט | רשימה מסודרת של בלוקי טקסט פשוט, ובתוכה בלוק טבלה אחד שניתן להזיז. |

ההיקף האישי (עמודת ה-people) **חל על כולם** — גם על מנהלי לוח ואדמינים. הבעלות
מקנה גישה להגדרות בלבד.

## פיתוח

```bash
pnpm install                                 # מהשורש של המונו-ריפו
pnpm --filter ./apps/docs-export dev:mock    # :8304 — מרנדר מחוץ ל-iframe של monday
pnpm --filter ./apps/docs-export test
pnpm --filter ./apps/docs-export lint
pnpm --filter ./apps/docs-export build       # -> dist/
```

`dev:mock` מריץ את האפליקציה מול stub של `monday-sdk-js` עם fixtures מציאותיים
(כולל סימולציה של מצבי כשל ב-storage) — ראו `src/dev-harness/README.md`.
זה גם ה-SDK שכל הטסטים רצים מולו.

לבדיקה בתוך monday עצמו: `pnpm --filter ./apps/docs-export tunnel`.

**פריסה לא נעשית ממחשב.** ראו `CLAUDE.md` בשורש הריפו.

## מסמכים

- `CLAUDE.md` — הארכיטקטורה, ההחלטות, והמלכודות. קראו אותו לפני שינוי.
- `CHANGELOG.md` — היסטוריית השינויים.
