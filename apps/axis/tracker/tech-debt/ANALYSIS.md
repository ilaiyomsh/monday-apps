- **Source:** Not in original audit — opened during Wave 1.4c known-debt cataloguing (see F033 catalog) when six `react-hooks/exhaustive-deps` warnings (lines 75, 82, 96, 109, 116, 123) were classified as `local-async-fn` pattern blocked behind god-file ban.

Result: 6 lint warnings vanish, file LOC drops, and each section is independently testable.
