# חבילת טיפול וניטור שגיאות — Tracker

תיקייה אחת המרכזת את **כל החומר** של יוזמת הטיפול והניטור בשגיאות: מסמכי תיעוד, סקריפטים של ה-workflows שהפיקו את הממצאים, ואינדקס שמצביע על כל קבצי המקור הרלוונטיים.

> **מטרת-העל:** כל שגיאה גם נתפסת (catch) וגם מנוטרת (monitor) — זורמת דרך `logger` אל sink מרכזי.

---

## מבנה

```
error-handling-bundle/
├── README.md              ← המסמך הזה
├── RELEVANT-SOURCES.md    ← אינדקס: כל תיקון → קובץ המקור החי + שורות
├── docs/                  ← 4 מסמכי התיעוד
└── workflows/             ← 2 סקריפטים שהפיקו את הביקורת והסקירה
```

> **למה אינדקס ולא עותקי מקור?** העתקת קבצי `src/` לתיקייה נפרדת יוצרת כפילות שסוטה (drift) מהקוד החי מיד. במקום זה, `RELEVANT-SOURCES.md` **מצביע על הקבצים החיים** ב-`src/` — אפס drift, וכל הפניה אומתה כקיימת (56/56 ✓).

---

## 1. `RELEVANT-SOURCES.md` — האינדקס

המיפוי המרכזי: לכל תיקון בתוכנית יש שורה עם **נתיב הקובץ החי + מספרי שורות + חומרה + מקור**, מקובץ לפי שלב (Phase 0–6). כולל גם **אינדקס הפוך** (קובץ → השלבים שנוגעים בו). זו נקודת הכניסה לניווט בקוד.

## 2. `docs/` — סדר קריאה מומלץ

1. **`error-handling-implementation-plan.md`** — *התחל כאן.* התוכנית המלאה (Phase 0–6), מטרת-העל, רצף, מדדים, ותקצירי מנהלים של שלושת המסמכים הבאים.
2. `error-handling-standard.md` — הסרגל: מתי שגיאה נחשבת מטופלת.
3. `error-handling-audit.md` — ביקורת ה-catch (213 מקורות, 51 פערים: 3 קריטי / 12 גבוה / 13 בינוני / 23 נמוך).
4. `sink-readiness.md` — ביקורת ה-monitor (510 מקורות, 311 מגיעים ל-logger / 199 dark = 39%).

## 3. `workflows/` — הסקריפטים שהפיקו את הממצאים

שני workflows רב-סוכניים (multi-agent), להרצה חוזרת דרך כלי ה-`Workflow`:

- `error-audit-workflow.js` — מפיק את `docs/error-handling-audit.md` (census + 2 readers + critic + verify).
- `sink-readiness-workflow.js` — מפיק את `docs/sink-readiness.md` (census + 2 classifiers + reconcile + verify).

> **אזהרת עלות:** כל workflow צרך ~3–7M tokens. אל תריץ את שניהם ברצף — זה הגיע למגבלת הסשן.

## תחזוקה

האינדקס מצביע על קוד חי, כך שהוא נשאר תקף כל עוד נתיבי הקבצים לא משתנים. אם קובץ מועבר/משונה שם — לעדכן את `RELEVANT-SOURCES.md` (ולהריץ מחדש את אימות ההפניות).
