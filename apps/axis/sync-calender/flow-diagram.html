🔁 Fallback — כשה-Google fetch נכשל

אם ה-webhook לא הצליח להביא אירועים מ-Google (Token פג, שגיאת רשת וכו׳), יורים Trigger עם channelId בלבד. ה-Action מזהה שאין eventId וחוזר למנגנון v2 — הוא עצמו יביא את האירועים עם Token טרי שמגיע בקריאה.

🚨 Webhook נכשל

events.list זרק שגיאה → catch → POST webhookUrl רק עם { channelId }.

✅ Action מציל את הסיטואציה

מזהה ש-eventId ריק → טוען syncToken → events.list עם Token טרי → sync-engine.processEvents על כל הבאץ׳.
מה אבד? שום אירוע. ה-Fallback מבטיח שכל שינוי ב-Google יגיע לבורד, גם אם ה-Token המאוחסן פג.
