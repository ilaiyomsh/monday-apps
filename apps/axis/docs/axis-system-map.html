מערכת Axis

מערכת אפליקציות monday.com לניהול משאבים וזמן — שני רכיבי-ליבה: תכנון ודיווח שעות, ורכיב-עזר לסנכרון יומן שמזין את דיווח השעות.

מבנה המערכת

1
Planner — תכנון תכנון פרויקטים והקצאת משאבים בתרשים Gantt. רכיב-ליבה עצמאי.
2
Tracker — דיווח שעות דיווח שעות-עבודה, חופשות ומחלות בממשק יומן. רכיב-ליבה.
↑   מזין אירועי יומן
＋
sync-calender — סנכרון יומן רכיב-עזר ל-Tracker: מסנכרן אירועים מ-Google Calendar כדי להזין את דיווח השעות.
🛠️ כלי מפתח בלבד — בנפרד מהמערכת קיים דשבורד בקרה (sync-calender-status) לניטור בריאות האפליקציות. הוא אינו חלק מהמערכת — המוצר עובד לחלוטין בלעדיו.
