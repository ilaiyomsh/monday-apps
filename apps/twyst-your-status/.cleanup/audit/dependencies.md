# Audit — dependencies (apps/twyst-your-status)

Scope: `apps/twyst-your-status/{src,server/src}` + the two `package.json` files.

Scanner baseline actually re-verified before writing this (so the findings below are all
*beyond* knip): `.cleanup/raw/knip-spa.json` and `knip-srv.json` report **zero** unused
dependencies, zero unlisted/phantom dependencies and zero unresolved imports in both
workspaces; `.cleanup/raw/eslint-spa.json` and `eslint-srv.json` are both empty (0
messages); `.cleanup/raw/jscpd/jscpd-report.json` reports 6 clones / 51 duplicated lines
(0.38%). I also cross-checked every bare import specifier in `src/`, `server/src/`,
`server/tests/`, `build.mjs` and the config files against both manifests — no phantom or
undeclared dependency exists.

Two ruled-out hypotheses, checked so nobody spends a batch on them: `@vibe/icons` **is**
tree-shaken (the built chunks contain 6/4/7/14/2 `viewBox` occurrences respectively, i.e.
only the ~15 imported icons, not the 5.7 MB set) — do not "optimize" the barrel import to
deep imports; and `monday-sdk-js`' `node-fetch` dependency does **not** reach the browser
bundle (0 occurrences of `node-fetch`/`whatwg-url`/`abort-controller` in
`dist/assets/index-*.js`).
